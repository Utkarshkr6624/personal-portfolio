# Utkarsh Choudhary — Portfolio

A simple personal site built with HTML, CSS, and JavaScript. No frameworks.

## Run it

Open `index.html` in your browser, or from this folder:

```bash
python -m http.server 5500
```

Then visit `http://localhost:5500`.

## Edit

- Email: change `EMAIL` at the top of `script.js`
- Photo: `assets/photo.jpg`
